## 二、JDK 25（LTS）核心新特性（对比 21/17）
### 1. 语言语法：更简洁、新手友好
- **实例主方法（JEP 512，正式）**
  不用写 `public static void main`，直接写：
  ```java
  void main() {
      System.out.println("Hello Java 25");
  }
  ```
  适合脚本、教学、小工具

- **原始类型模式匹配（JEP 507，第3次预览）**
  `instanceof` / `switch` 支持 `int/double/long` 等基本类型：
  ```java
  Object obj = 3.14;
  if (obj instanceof double d) { ... }

  String s = switch (num) {
      case int i when i > 0 -> "正整数";
      case double d -> "小数";
      default -> "其他";
  };
  ```

- **模块导入声明（JEP 511）**
  ```java
  import module java.net.http; // 一次性导入模块所有包
  ```

### 2. 并发：虚拟线程完善 + 结构化并发/作用域值
- **Scoped Values（JEP 506，正式）**
  替代 ThreadLocal，**不可变、线程安全、更低开销**，跨线程传参更稳

- **结构化并发（JEP 505，第5次预览）**
  把一组相关任务当一个单元，统一取消/异常：
  ```java
  try (var scope = new StructuredTaskScope<>()) {
      Future<Integer> f1 = scope.fork(() -> task1());
      Future<String> f2 = scope.fork(() -> task2());
      scope.join();
  } // 自动取消所有未完成任务
  ```

- **虚拟线程优化**
  修复 pinning、同步块性能、大量线程调度问题

### 3. JVM & 内存：大幅瘦身、更快启动
- **紧凑对象头（正式）**
  64位机对象头从 **96–128bit → 64bit**
  → 小对象内存占用 **-30%**，GC 更快、缓存更好

- **AOT 编译增强（JEP 515）**
  简化命令、支持方法分析，**启动/热身加速 30%+**

- **String 哈希优化**
  `String.hashCode` 缓存与计算加速，**Map/Set 性能 +20~40%**

### 4. GC：低延迟全面成熟
- **分代 Shenandoah GC（正式）**
  大堆停顿 **-40%**，内存利用率更高

- **ZGC 持续优化**
  更低延迟、更大堆支持

### 5. 安全：抗量子、PEM 编码
- **抗量子密码（JEP 510）**
  支持 ML-KEM 等后量子算法

- **加密对象 PEM 编码（正式）**
  密钥/证书轻松转 PEM 格式

### 6. 移除/废弃
- **彻底移除 32位 x86 支持（JEP 503）**
- 清理大量废弃 API

## 三、JDK 26（非 LTS）核心新特性（对比 25）
### 1. 语言：值类（Valhalla）重大突破
- **值类（Value Classes，预览）**
  无标识、不可变、可扁平化存储，**内存占用 -40%~60%**：
  ```java
  value class Point(int x, int y) {} // 无对象头、连续内存
  ```
  测试：`Integer` 16B → 4B（-75%）；`LocalDate` 24B → 16B（-33%）

- **原始类型模式匹配（第4次预览）**
  更严格检查、更少bug

- **惰性常量（JEP 526，预览）**
  ```java
  @LazyConstant
  static final Config CONFIG = loadConfig(); // 首次访问才计算
  ```

### 2. 并发：结构化并发第6轮预览
- 更稳定 API、更好集成虚拟线程、更清晰异常传播

### 3. 性能：AOT、GC、网络全面加速
- **AOT 对象缓存（JEP 516，正式）**
  支持 **ZGC/Shenandoah/G1** 全GC，堆外缓存对象，**启动再加速**

- **G1 GC 优化（JEP 522）**
  减少同步开销，**吞吐量 +15%**；更及时回收大对象

- **HTTP/3 客户端（正式）**
  解决队头阻塞，**弱网延迟 -50%+**

### 4. 移除
- **彻底移除 Java Applet API**

## 四、8 → 17 → 21 → 25 → 26 关键差异速览（精华）
### 语言语法
- **8**：Lambda/Stream/Optional
- **17**：record/sealed/switch 表达式/文本块
- **21**：虚拟线程/switch 模式匹配
- **25**：**实例main/原始类型模式/模块导入**
- **26**：**值类/惰性常量**

### 并发（最影响后端）
- **21**：虚拟线程（正式）
- **25**：**Scoped Values（正式）+ 结构化并发（预览）**
- **26**：结构化并发完善、值类+虚拟线程组合

### GC & 内存
- **17**：ZGC/Shenandoah 正式
- **21**：分代ZGC
- **25**：**紧凑对象头 + 分代Shenandoah**
- **26**：**值类内存 -50%+、G1 吞吐量提升**

### 启动/云原生
- **11+**：jlink/CDS
- **25**：AOT 增强
- **26**：**全GC AOT缓存、HTTP/3**
